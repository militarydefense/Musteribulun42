Not: GTİP kodu ile firma bazında ithalatçı listesi resmi kaynaklarda herkese açık değildir. Program, 9303 için ülkelerin ithalat hacmini (ve Türkiye'den aldıkları payı) gösterir; seçtiğiniz ülkelerde GTİP koduna karşılık gelen ürün terimleriyle firma taraması yapar. Firma bazlı gümrük verisi için ImportGenius, Panjiva, Volza gibi ücretli kaynaklar kullanılabilir (CSV olarak içe aktarılabilir).

Tarama ayarları

Anahtarlar nasıl alınır?

  1. Google: console.cloud.google.com → yeni proje → "Places API (New)", "Geocoding API" ve "YouTube Data API v3"ü etkinleştirin → Kimlik bilgileri → API anahtarı oluşturun. Faturalandırma hesabı gereklidir.
  2. Serper.dev: serper.dev'e kayıt olun, panelden API anahtarını kopyalayın (ilk 2.500 sorgu ücretsiz).
  3. Meta (isteğe bağlı): developers.facebook.com → uygulama oluşturun → Instagram Graph API → işletme hesabınıza bağlı uzun ömürlü erişim anahtarı ve IG kullanıcı ID'si.

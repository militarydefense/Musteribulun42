| s | part |
|---|---|

| 3–6.5 | close globe spin (211 frames, `spin.js`, cloud check via `cloudcheck.py`) |
| 6.5–22 | 35-still zoom (`stills.js`, `plan.json`, `path.json`, shared `zoom.py`) |
| 22–23 | dive |
| 23–35 | 360° pan of the 2023 drone photosphere (Yasin çiçek / Google), Mount Ararat |

Music: `music/zoomtosecrets_trend.mp3` (`START=3.0 DROP=22.2`). VO lines in `lines.json`.
Capture lesson: Google Earth opens in *Exploration* mode (clouds on); every frame is
checked and the *Clean* style re-selected if clouds appear.
